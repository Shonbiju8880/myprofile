HTML Tags Reference

HTML Tag My Explanation
<html>The root element that wraps all the content on the page.
<head>Contains machine-readable information (metadata) about the document.
<title>Sets the title of the webpage shown in the browser tab.
<body>Represents the content of the document that is visible to the user.
<h1> to <h6>Used to create headings, with <h1> being the most important.
<p>Used to define a paragraph of text.
<a>Creates a hyperlink to other web pages, files, or locations.
<img>Embeds an image into the document.
<div>A generic container for flow content, used for styling and layout.
<ul> & <ol>Creates unordered (bulleted) and ordered (numbered) lists.
<li>Defines a list item inside <ul> or <ol>.
<table>Represents tabular data arranged in rows and columns.
<form>Represents a document section containing interactive controls for submitting information.
<input>Used to create interactive controls for web-based forms (text, checkboxes, etc.).
<button>An interactive element activated by a user with a mouse, keyboard, or touch.
