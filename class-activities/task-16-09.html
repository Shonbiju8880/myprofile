Tags I used on this page:

  • <html> - The root of the HTML document.
  • <head> - Contains metadata and the page title.
  • <title> - Sets the name shown on the browser tab.
  • <body> - Holds all the visible content.
  • <div> - A container used for layout and styling.
  • <h1> and <h2> - Used for headings.
  • <p> - Used for paragraphs of text.
  • <strong> - Makes text bold and important.
  • <ul> and <li> - Creates an unordered list.
  • <a> - Creates a hyperlink (like the button below).
